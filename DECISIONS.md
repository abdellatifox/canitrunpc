# CanItRunPC — decisions

Written 2026-09-15 when the site was forked from RunsOnMyPC. The data, image
and exclusion rules are inherited unchanged; identity, design and every word
of copy are this site's own.

## Identity
- Domain: **canitrunpc.com**, chosen by the owner on 2026-09-15 (unregistered per
  Verisign RDAP, no Wayback history). It replaced willitrunpc.com, which is
  confusable with the live willirunit.com. Brand **CanItRunPC**, spaced
  "Can It Run PC", logo wordmark "canitrun" + PC badge.
  Contact `hello@canitrunpc.com`. All of it lives in `src/lib/site.ts` only.
- Language: **English**, `dir="ltr"`. SEMrush database: **us**.
- Year focus: **2027** via `src/lib/year.ts` (`SEO_YEAR` rolls over each September).
- Primary competitor: **pcgamecheck.com**. Cover the same topics; never reuse its text.

## Design
- Light "spec sheet": warm paper ground (#F4F1E8), ink text and 2px ink borders,
  hard offset shadows, signal orange (#C2410C) for actions, deep teal (#0B6E7F)
  for readouts. Space Grotesk / Public Sans / IBM Plex Mono.
- Deliberately unlike pcgamecheck, PCGameFit and RunsOnMyPC (all dark).
- Game logos sit on dark ink tiles, because nearly every logo is white.
- Every colour is a token in `src/styles/global.css`.

## Content
- Original prose only. Articles are generated by `scripts/build-blog.mjs`:
  numbers come from the data, and each article asserts the data still supports
  its sentences, failing the build otherwise.
- Tool pages, about, editorial standards, privacy and terms still carry
  RunsOnMyPC's wording — rewrite before launch (PLAN.md week 1).

## Data rule
- No value without a source. Game requirements come from Steam `appdetails`
  (publisher-stated); GPU/CPU scores from curated, sourced datasets.
- Missing = `null`, shown as "not stated". Never estimated.
- A tool either calculates from real data or refuses and says why.
- Keys are Steam **appid**, never slugs.

## Image policy
- **Logos only** (SteamGridDB `nsfw=false&humor=false&types=static`).
- **No imagery depicting women, ever.** Games without a logo get an initials tile.

## Excluded content
- Central list `data/excluded-games.mjs`, enforced at build and on live Steam paths:
  Grand Theft Auto (whole series, GTA+), The Witcher 1/2/3 (GWENT, "thronebreaker:"),
  Doki Doki Literature Club!, Business Tour, Governor of Poker 3, gambling titles.
- GTA 6 is excluded too, although it is the largest low-difficulty keyword set in
  the niche (PLAN.md §2-d). Lifting it is the owner's call, for this site only.

## Cloudflare
- No resources yet. Run `npm run cf -- whoami` before any create. Never the
  Abdellatifbrands account, never anything named critvolt-*, never RunsOnMyPC's
  or PCGameFit's resources.
